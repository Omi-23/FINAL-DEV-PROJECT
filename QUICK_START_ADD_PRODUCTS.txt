═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ "Forbidden" or "Unauthorized" error
   → You're not logged in as admin
   → Make sure email matches: www.meselfomiofficial@gmail.com
   → Check server/.env has: ADMIN_EMAILS=www.meselfomiofficial@gmail.com

❌ Admin Dashboard not showing
   → Logout and login again
   → Check browser console (F12) for errors
   → Verify backend is running on port 5001

❌ Products still not showing
   → Refresh page (F5)
   → Check Admin Dashboard → Manage Products (should list your products)
   → Check browser Network tab (F12) for API errors
